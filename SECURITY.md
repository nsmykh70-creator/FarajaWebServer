# Security Policy / Безопасность

## Поддерживаемые версии / Supported versions

| Version | Supported |
|---------|-----------|
| v16.x   | ✅        |
| < v16.0 | ❌ (обновитесь / please upgrade) |

## Как сообщить / Reporting

Нашли уязвимость (RCE, path traversal, повышение прав)?
Создайте issue с меткой `security`: опишите проблему по-русски или
по-английски и приложите шаги воспроизведения.
Мы постараемся выпустить фикс в ближайшем релизе. Спасибо!

## Что уже сделано / Hardening in place

- Внешний апдейтер проверяет ZIP (CRC, zip-slip, лимиты размера).
- Обновления скачиваются только с `https://github.com/` и проверяются (SHA256).
- Релизные ассеты проверяются по CRC перед распаковкой.
- Apache слушает только `127.0.0.1`; наружу — лишь Nginx.
